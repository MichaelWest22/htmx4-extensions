# debug

Logs all htmx events to the console via `console.debug` (or `console.log` with a `DEBUG:` prefix as fallback).

## Install

```html
<script src="/path/to/ext/debug.js" defer></script>
```

## Usage

Once loaded, all htmx events are logged globally.

> **Note**: To see `console.debug` output in Chrome DevTools, enable Verbose level in the Console's levels dropdown.
