# remove-me

Removes an element after a specified time interval.

## Install

```html
<script src="/path/to/ext/remove-me.js" defer></script>
```

## Usage

```html
<!-- Removes this div after 1 second -->
<div remove-me="1s">To Be Removed...</div>
```

Supports `ms`, `s`, and `m` time units. Also accepts `data-remove-me` for HTML validity.
